Ember Vault — a top-down stealth game. You are the lantern thief: steal every ember in three halls and slip out the green door unseen. Guards patrol with vision cones that stop at walls and crates, lamplight betrays you, tall grass hides you, and a tossed coin pulls a guard away. Run and they hear you; crouch and they never see you.

## Run it

```sh
node main.ts
```

Serve `game/` with any static server and open `game/index.html` in desktop Chrome to play: WASD or arrows to move, Shift to run, C to crouch, click to toss a coin, R to retry the level.
